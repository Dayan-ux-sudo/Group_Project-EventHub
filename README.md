#  EventHub is a comprehensive web-based platform designed as a single destination for all campus events — including academic workshops, hackathons, club meetings, social gatherings, seminars, and more.

# Core features include:
### Event Discovery: Browse events in grid/list views, with powerful search and filters (by category, date, location, popularity).
### Event Management: Organizers (students, clubs, faculty) can create, edit, and manage events with details like description, date/time, location (with map integration), capacity, and categories (e.g., workshop, social, academic).
### RSVP & Attendance: Users can RSVP easily, view attendee lists (with avatars for social feel), and track capacity limits.
### Notifications & Reminders: Automated email reminders (e.g., 24 hours before event) and potential in-app notifications.

The project has two main categories: The frontend and the backend. 
The frontend has the user interface while the the backend hosts the server on which the application runs from.
The whole project is hosted on Docker.
To run the frontend: run npm run dev
To run the backend: run python manage.py runerver
